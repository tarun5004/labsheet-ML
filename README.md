# Machine Learning Lab Sheets

Each labsheet has its own folder. Every numbered experiment is a separate,
independently runnable Python file, and generated files stay in that labsheet's
`outputs` directory.

## Labsheet 1

Install the dependencies once:

```powershell
python -m pip install -r requirements.txt
```

Run any experiment, for example:

```powershell
python "Labsheet 1\question_01.py"
python "Labsheet 1\question_35.py"
```

`Labsheet 1` contains `question_01.py` through `question_35.py`, matching the
35 experiments in MCA201P Lab Sheet 01. The Iris dataset is bundled with
scikit-learn, so no dataset download is required.
